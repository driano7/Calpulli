================================================================================
AMAXING / CALPULLI CDMX — INFORMACIÓN PARA LLMS Y CONSUMO DE CONTENIDO
================================================================================

Este archivo describe qué ofrece el sitio, cómo consumirlo y qué información
está disponible para que un LLM pueda responder preguntas sobre Amaxing y la
CDMX sin inventar datos.

--------------------------------------------------------------------------------
1. QUÉ ES CALPULLI CDMX
--------------------------------------------------------------------------------

Plataforma de turismo local en la Ciudad de México. Ofrece tours guiados,
journeys editoriales culturales, guías interactivas, mapas de barrio, local
picks mensuales y reservas con ticket QR. Todo bilingüe (español / inglés).

Sitio principal: https://donovan-amx.vercel.app

--------------------------------------------------------------------------------
2. CONTENIDO DISPONIBLE PARA LLMS
--------------------------------------------------------------------------------

A. TOURS (/tours)
   - 12 tours comerciales con checkout (reservables).
   - Cada uno tiene: título, tagline, descripción, puntos de encuentro,
     itinerario, destacados, precio, duración, máximo de personas, categoría.
   - Ejemplos: comida callejera Centro Histórico, mezcal y pulque, Coyoacán,
     Xochimilco, museos, etc.
   - Datos en: data/toursData.js

B. JOURNEYS EDITORIALES (/journeys)
   - 6 caminatas culturales NO reservables (contenido para leer y recorrer):
     1. Luchas — Lucha Libre en Arena México y Arena Coliseo.
     2. Centro Histórico — El futuro se pintó aquí.
     3. Chapultepec — De los Dioses a Emperadores.
     4. Roma-Condesa — La ciudad que se puso de moda.
     5. Jamaica — Mirar más allá de las flores.
     6. Antropología — Museo Nacional de Antropología.
   - Cada journey tiene título, subtítulo, introducción, momentos, pasos,
     observaciones, fotos verificadas (Wikimedia Commons) y fuentes.
   - Datos en: data/journeys/*.js y data/journeysData.js

C. GUÍAS INTERACTIVAS (/guides)
   - 5 recorridos autoguiados: Condesa, Centro, Chapultepec II, Chimalistac, UNAM.
   - Cada uno tiene título, resumen, imagen, color de acento y MDX con contenido.
   - Datos en: data/selfGuidesData.js y data/guides/*.mdx

D. MAPAS (/maps)
   - 5 mapas curados de la CDMX: comida tradicional, zonas con precaución,
     vida nocturna, joyas escondidas, top atracciones.
   - Cada mapa tiene título, descripción, embed de My Maps y highlights.
   - Datos en: data/cdmxMapsData.js y data/maps/*.mdx

E. LOCAL PICKS (/local)
   - Guía mensual curada por chilangos para visitantes de 2-7 días.
   - 3 festividades fijadas todo el año (rosa mexicano, con chincheta):
     Año Nuevo, 16 de Septiembre, Día de Muertos.
   - 6 picks que rotan cada mes.
   - Datos en: data/local-picks/*.mdx

F. BLOG DE EMERGENCIA (/blog/Info)
   - Teléfonos de emergencia CDMX 2026: 911, Policía Turística
     WhatsApp +52 55 4891 1116, Locatel *0311, Protección Civil
     55 5683 2222, Denuncia Anónima 089.
   - Qué hacer antes, durante y después de un sismo (CENAPRED / Protección Civil).
   - Dónde encontrar a la Policía Turística (Centro, Reforma, Coyoacán,
     Xochimilco, Polanco; 24/7; hablan inglés, francés, italiano, náhuatl,
     totonaco y algunos alemán/japonés/mandarín).
   - Zonas con más precaución en CDMX (Tepito, La Lagunilla, Centro
     Histórico periferia nocturna, Iztapalapa periferia, Gustavo A. Madero
     periferia, Mercado de Sonora).
   - Datos en: data/blog/Info/*.mdx

3. CÓMO CONSULTAR LA INFORMACIÓN (APIs para LLMs)
--------------------------------------------------------------------------------

A. Knowledge Graph API
   GET /api/knowledge/{entity}?lang=es&category=&neighborhood=&q=&limit=&offset=
   Entidades: Tour, Itinerary, Map, LocalPick, Neighborhood, Category, Place.
   CORS abierto, caché CDN 1h. Spec: public/openapi.json

B. MCP Server (read-only para agentes IA)
   Herramientas: search_tours, get_tour_details, match_tours_to_preferences,
   build_half_day_plan, build_day_plan, build_itinerary, combine_tours_and_places,
   find_activities_near, find_before_or_after_tour, suggest_for_time_available,
   suggest_for_location, suggest_for_weather, suggest_for_first_time_visitor,
   explain_recommendation.
   Recursos: calpulli://tours, tours/{id}, places/{id}, neighborhoods/{id},
   itineraries/{id}, taxonomies, knowledge-graph, data-policy, attribution.

C. llms.txt y robots.txt
   public/llms.txt — índice + sección máquina con endpoints.
   public/robots.txt — Allow explícito a GPTBot, Claude, Perplexity, etc.

D. Sitemap dinámico
   pages/sitemap.xml.js — rutas + tours + guides + maps + local + blog.

--------------------------------------------------------------------------------
4. RESERVAS Y CHECKOUT
--------------------------------------------------------------------------------

A. Tours y experiencias sí se reservan con checkout (Stripe, efectivo, cripto).
B. Journeys editoriales NO se reservan: son contenido cultural gratuito.
C. Se puede pagar como invitado sin crear cuenta (se guarda el ticket en localStorage).
D. Usuario autenticado puede buscar sus reservas en /bookings con filtros:
   tipo de actividad (dropdown con foto + título), fecha (±1 mes desde hoy) y nombre.

--------------------------------------------------------------------------------
5. VALOR QUE APORTA
--------------------------------------------------------------------------------

- Contenido verificado y bilingüe sin inventar datos.
- Fotografía con licencia verificada (Wikimedia Commons, créditos individuales).
- Información de emergencia actualizada (2026) para visitantes de CDMX.
- API abierta para LLMs y agentes IA (MCP, Knowledge Graph, llms.txt).
- Reservas con ticket QR descargable.
- Pagos con tarjeta, efectivo o cripto (Ethereum, Base, Lightning).
- GDPR: exportar/eliminar datos personales, cifrado AES-256-GCM.
